Claude Skill Vault
A curated vault of viral Claude Code plugins, agent skills, and workflow repositories on GitHub, organized by use case.
1. Coding & Senior Dev Workflows
￼ Superpowers (⁠obra/superpowers⁠) — Agentic skills framework and TDD-enforced software development workflow.
￼ Matt Pocock Skills (⁠mattpocock/skills⁠) — Engineering and workflow skills straight from Matt Pocock's ⁠.agents⁠ setup.
￼ ECC (Everything Claude Code) (⁠affaan-m/everything-claude-code⁠) — Agent harness optimization system with skills, memory, security, and research-first development.
￼ Karpathy Skills (⁠forrestchang/andrej-karpathy-skills⁠) — Single ⁠CLAUDE.md⁠ ruleset derived from Andrej Karpathy's observations on LLM coding pitfalls.
￼ Ponytail (⁠DietrichGebert/ponytail⁠) — Makes your AI agent think like a lazy senior dev (YAGNI, stdlib-first, fewer lines of code).
￼ Agent Skills (⁠wshobson/agents⁠) — Production-grade engineering skills, agents, and commands for AI coding tools (also see addyosmani/agent-skills).
2. Research & Codebase Understanding
￼ Graphify (⁠safishamsi/graphify⁠) — Turns a codebase or folder into a queryable knowledge graph.
￼ Agent Reach (⁠Panniantong/Agent-Reach⁠) — CLI and skill that lets AI agents search and read X/Twitter, Reddit, YouTube, GitHub, and more with zero API fees.
￼ Understand Anything (⁠lum1104/Understand-Anything⁠) — Turns any codebase into an interactive, searchable knowledge graph.
￼ Last 30 Days (⁠mvanhorn/last30days-skill⁠) — Researches any topic across Reddit, X, YouTube, Hacker News, and Polymarket from the past month and synthesizes a summary.
￼ CareerOps (⁠career-ops-hq/career-ops⁠) — Open-source AI job search agent that scans job boards, scores roles against your CV, and tailors resumes.
￼ REA (⁠morluto/rea⁠) — Reverse-engineering agent framework for inspecting native binaries, Electron apps, and websites.
3. Large Projects, Memory & Token Management
￼ GStack (⁠garrytan/gstack⁠) — Garry Tan’s opinionated setup with defined roles (CEO, designer, QA, engineer).
￼ Caveman (⁠JuliusBrussee/caveman⁠) — Cuts ~65% of output tokens by instructing the agent to communicate in ultra-concise "caveman" speech.
￼ Claude-Mem (⁠thedotmack/claude-mem⁠) — Persistent memory across sessions that compresses session history and injects relevant context later.
￼ Headroom (⁠headroomlabs-ai/headroom⁠) — Context compression layer that shrinks tool outputs, logs, and files to save tokens.
￼ GSD (Get Shit Done) (⁠gsd-build/get-shit-done⁠) — Lightweight meta-prompting, context engineering, and spec-driven development system.
￼ BMAD Method (⁠bmad-code-org/BMAD-METHOD⁠) — Breakthrough Method for Agile AI-Driven Development for structured planning and multi-agent execution.
4. Design & Visuals
￼ UI UX Pro Max (⁠nextlevelbuilder/ui-ux-pro-max-skill⁠) — Design intelligence skill with palettes, typography rules, and UX guidelines across frameworks.
￼ Taste Skill (⁠Leonxlnx/taste-skill⁠) — Gives coding agents art direction and layout systems so web builds don't look like generic AI templates.
￼ Archify (⁠tt-a1i/archify⁠) — Turns ideas, plans, or codebases into interactive HTML/SVG architecture diagrams.
￼ Impeccable (⁠pbakaus/impeccable⁠) — Design vocabulary and critique/audit skill to catch UI "AI slop" before shipping.
￼ PPT Master (⁠hugohe3/ppt-master⁠) — Generates natively editable PowerPoint (⁠.pptx⁠) decks with charts, shapes, and speaker notes from documents.
￼ Diagram Design (⁠cathrynlavery/diagram-design⁠) — Generates 45+ types of editorial HTML + SVG diagrams.
5. Writing, Productivity & Video
￼ Skills by Anthropic (⁠anthropics/skills⁠) — Anthropic’s official reference skills and the Agent Skills specification.
￼ Open Montage (⁠OpenMontageInc/OpenMontage⁠) — Open-source agentic video production and montage pipeline.
￼ Hyperframes (⁠heygen-com/hyperframes⁠) — Video rendering framework that lets agents write HTML/GSAP animations and render them to MP4.
